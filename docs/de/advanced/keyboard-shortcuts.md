# Tastaturkürzel

Meistere OwnShell mit diesen produktivitätssteigernden Tastaturkürzeln.

## Globale Shortcuts

| Kürzel         | Aktion                         |
| -------------- | ------------------------------ |
| `Cmd/Strg + N` | Neue SSH-Verbindung            |
| `Cmd/Strg + T` | Neuer Terminal-Tab             |
| `Cmd/Strg + W` | Aktuellen Tab schließen        |
| `Cmd/Strg + Q` | OwnShell beenden               |
| `Cmd/Strg + ,` | Einstellungen öffnen           |
| `Cmd/Strg + K` | Schnellsuche / Command Palette |

## Navigation

| Kürzel           | Aktion              |
| ---------------- | ------------------- |
| `Cmd/Strg + 1-9` | Zu Tab 1-9 wechseln |
| `Cmd/Strg + [`   | Vorheriger Tab      |
| `Cmd/Strg + ]`   | Nächster Tab        |

## Terminal

| Kürzel         | Aktion                         |
| -------------- | ------------------------------ |
| `Strg + C`     | Aktuellen Prozess unterbrechen |
| `Strg + D`     | Shell beenden (trennen)        |
| `Strg + L`     | Terminal leeren                |
| `Cmd/Strg + F` | Im Terminal suchen             |
| `Cmd/Strg + +` | Schriftgröße erhöhen           |
| `Cmd/Strg + -` | Schriftgröße verringern        |

## Datei-Browser (SFTP/S3)

| Kürzel         | Aktion                       |
| -------------- | ---------------------------- |
| `Cmd/Strg + U` | Datei hochladen              |
| `Cmd/Strg + D` | Ausgewähltes herunterladen   |
| `Cmd/Strg + R` | Dateiliste aktualisieren     |
| `Entf`         | Ausgewählte Dateien löschen  |
| `F2`           | Ausgewählte Datei umbenennen |

## Datenbank-Client

| Kürzel             | Aktion                             |
| ------------------ | ---------------------------------- |
| `Cmd/Strg + Enter` | Query ausführen                    |
| `Cmd/Strg + /`     | Zeile kommentieren/entkommentieren |
| `Cmd/Strg + F`     | In Query suchen                    |

## Vault

| Kürzel            | Aktion                          |
| ----------------- | ------------------------------- |
| `Cmd/Strg + N`    | Neuer Vault-Eintrag             |
| `Cmd/Strg + E`    | Ausgewählten Eintrag bearbeiten |
| `Cmd/Strg + Entf` | Ausgewählten Eintrag löschen    |
| `Cmd/Strg + C`    | Wert in Zwischenablage kopieren |

## Command Palette

Drücke `Cmd/Strg + K` um die Command Palette zu öffnen:

Tippe um schnell zu finden:

- Verbinde zu jedem Server
- Öffne jede Datenbank
- Starte jeden Tunnel
- Führe jede Aktion aus

## Tipps & Tricks

### Multi-Cursor Bearbeitung (SQL-Editor)

- `Cmd/Strg + Klick` - Cursor hinzufügen
- `Cmd/Strg + D` - Nächstes Vorkommen wählen
- `Cmd/Strg + Shift + L` - Alle Vorkommen wählen

### Schnelle Terminal-Aktionen

- `Cmd/Strg + Klick URL` - Link im Browser öffnen
- `Cmd/Strg + Klick Dateipfad` - Datei in SFTP öffnen

## Plattform-Unterschiede

### macOS

- `Cmd` = Command-Taste (⌘)

### Windows/Linux

- `Strg` = Steuerungstaste

Einige Shortcuts nutzen plattformspezifische Tasten - OwnShell passt sich automatisch an deine Plattform an!
