# Tastenkürzel

OwnShell läuft unter macOS; ⌘ ist die Command-Taste.

## Workspace

| Kürzel | Aktion |
| --- | --- |
| ⌘B | Schmale Seitenleiste umschalten |
| ⌘⇧B | Seitenleiste ein- oder ausklappen |
| ⌘W | Aktives Terminal-Panel und seine Sitzung schließen |
| ⌘Q | OwnShell beenden |

## Terminal

| Kürzel | Aktion |
| --- | --- |
| Ctrl+⇧S | Snippets-Panel ein- oder ausblenden |

## Dateien

| Kürzel | Aktion |
| --- | --- |
| ⌘S | Datei im Editor speichern |
| Esc | Editor schließen |

## Datenbanken

| Kürzel | Aktion |
| --- | --- |
| ⌘↩ | Abfrage in der Abfragekonsole ausführen |

## API-Client

Diese funktionieren, solange der API-Client den Fokus hat und kein Menü oder Dialog geöffnet ist.

| Kürzel | Aktion |
| --- | --- |
| ⌘↩ | Request senden (Verbinden bei WebSocket) |
| ↩ im URL-Feld | Request senden |
| ⌘S | Request speichern |
| Esc | Laufenden Request abbrechen (Trennen bei WebSocket) |
| ⌘↩ im WebSocket-Eingabefeld | Nachricht senden |
| ↑ / ↓, ↩ oder Tab, Esc | Variablen-Autovervollständigung bewegen, auswählen oder schließen |

## Projekte

| Kürzel | Aktion |
| --- | --- |
| ⌘P | Datei in der Code-Ansicht per Schnellsuche öffnen |
| ⌘F | In der geöffneten Datei suchen |
