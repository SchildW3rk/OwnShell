# OwnShell Dokumentation

Willkommen zur offiziellen OwnShell Dokumentation!

## Was ist OwnShell?

OwnShell ist die erste **local-first DevOps-Plattform**, die SSH, Datenbanken, Docker, S3 und Secrets Management in einer schönen App vereint.

## Hauptfunktionen

- 🔐 **Bank-Level Verschlüsselung** - AES-256-GCM für alle gespeicherten Daten
- 💾 **100% Lokale Speicherung** - Deine Daten verlassen nie dein Gerät
- 🚀 **Keine Cloud nötig** - Funktioniert vollständig offline nach Aktivierung
- 🔓 **Kein Lock-In** - Voller Import/Export deiner Konfiguration
