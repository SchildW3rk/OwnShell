# Keyboard shortcuts

OwnShell runs on macOS; ⌘ is the Command key.

## Workspace

| Shortcut | Action |
| --- | --- |
| ⌘B | Toggle the slim sidebar |
| ⌘⇧B | Collapse or expand the sidebar |
| ⌘W | Close the active terminal pane and its session |
| ⌘Q | Quit OwnShell |

## Terminal

| Shortcut | Action |
| --- | --- |
| Ctrl+⇧S | Show or hide the snippets panel |

## Files

| Shortcut | Action |
| --- | --- |
| ⌘S | Save the file in the editor |
| Esc | Close the editor |

## Databases

| Shortcut | Action |
| --- | --- |
| ⌘↩ | Run the query in the query console |

## API client

These work while the API client has focus and no menu or dialog is open.

| Shortcut | Action |
| --- | --- |
| ⌘↩ | Send the request (Connect for WebSocket) |
| ↩ in the URL field | Send the request |
| ⌘S | Save the request |
| Esc | Cancel a running request (Disconnect for WebSocket) |
| ⌘↩ in the WebSocket composer | Send the message |
| ↑ / ↓, ↩ or Tab, Esc | Move, pick or close variable autocomplete |

## Projects

| Shortcut | Action |
| --- | --- |
| ⌘P | Quick open a file in the code view |
| ⌘F | Search in the open file |
